# シーンメーカー

背景の画像をまとめて入れると、ココフォリアの「シーン」を一括で作るツール。できた ZIP をルームデータとして読み込むと、シーン一覧に並ぶ。全シーンに同じ前景（枠）を付ける、フィールドの大きさを画像の形に合わせる、5MB を超える静止画を縮小する、までをまとめて済ませられる。

**公開サイト: https://shiki365.github.io/scene-maker/**

手元で使う場合も、`index.html` をブラウザで開けば動く（サーバー不要・インストール不要。ZIP を作る JSZip だけ cdnjs から読むので、ネットにはつながっている必要がある）。

全シーンに付ける枠は [前景フレームメーカー](https://shiki365.github.io/foreground-frame-maker/)、動く素材は [場面転換素材メーカー](https://shiki365.github.io/scene-transition-maker/) で作れる。ほしいツールの要望や感想は [マシュマロ](https://marshmallow-qa.com/jisg2c3imbza76d) へ。

## できること

- **画像 1 枚が 1 シーン** — 背景の画像をドラッグ＆ドロップ（何枚でも）。シーンタイトルはファイル名。同じ中身の画像は置き場で 1 枚にまとめる。PNG・JPEG・GIF・WebP（動く WebP・APNG もそのまま入る）
- **シーンごと** — タイトル、背景、前景、フィールドの大きさ（マス）、グリッド（表示・間隔）、画像のはめ方（伸ばす / 切り抜く）、シーン切替メッセージ。盤面の見本つき
- **まとめて設定** — 共通の前景（全シーンに同じ枠）、長い辺を何マスにするかを決めて全シーンを背景の形に合わせる、グリッド・はめ方を全シーンにそろえる、並べ替え（ドラッグ・↑↓）、複製
- **5MB を超える静止画は縮小して書き出す** — 形を保ったまま 5MB 以下に。動く画像（動く WebP・APNG・GIF）は縮小せず、知らせる
- **書き出し 2 種**
  - **ルームデータ（ZIP）** — 「新しいシーンとして追加」か「前に入れたシーンを上書き（手直し用）」
  - **素材（ZIP）** — 使った画像を `背景/` `前景/` に分けて、分かる名前で。ルームデータの読み込みでは、画像はココフォリアの画像選択の一覧（自分の素材）に入らないので、あとで素材として選びたいときはこれを展開して、ココフォリアの画像選択の画面にドロップする
- 元に戻す / やり直す（最大 150 歩、Ctrl+Z / Ctrl+Y）、自動保存（設定は localStorage、画像は IndexedDB）、プロジェクトファイル（画像も入る）
- BGM・効果音は扱わない（ルームデータに音声を入れる場所が無いため）。ルームデータを読み込んで書き換える機能も無い

## ファイル

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面、CSS、使い方の説明 |
| `favicon.svg` | ブラウザのタブに出るアイコン |
| `ogp.png` | SNS で共有したときの画像（元は `media/ogp.html`。`media/` は公開しない） |
| `roomdata.v1.js` | 中身（entities）→ ルームデータ ZIP（UI に依存しない。ほかの ZIP 系ツールと共通の土台） … `window.CcfRoomData` |
| `model.v1.js` | 状態の初期値、古いデータの補正、大きさの提案、状態 → ココフォリアのシーン … `window.SceneModel` |
| `app.v1.js` | 画面の結線、画像の置き場、縮小、書き出し |

JS を直したら、`index.html` の `?v=` の番号とフッターの版を上げる。

## ココフォリアの内部の形に頼っている所

**CCFOLIA 1.37.4（`main.09686af1.js`）を 2026-10-02 に読んだ内容**で作っている。ココフォリアが更新されたら、ここを確かめ直す。

- ルームデータの形: `__data.json`（`meta.version` 1.1.0、`entities`、`resources`）、画像は ZIP の直下に `<SHA-256>.<拡張子>`、`.token`
- 画像ファイルを入れられる欄: `backgroundUrl` `foregroundUrl` `coverImageUrl` `imageUrl` `iconUrl` `thumbnail`
- シーンの欄: `name` `text` `backgroundUrl` `foregroundUrl` `fieldObjectFit`（`fill` / `cover`）`fieldWidth` `fieldHeight`（マス。1 マス = 24px、画面の入力は 0〜1000）`displayGrid` `gridSize` `markers` `order` と、BGM・効果音の欄（新しいシーンと同じ既定値で埋める）
- 読み込みは ID ごとの置き換え（新しい ID なら追加）。`room` が `{}` なら今の盤面は変わらない
- 画像の上限 5MB
- `.token` はわざと合わせていない。読み込むときに「外部ツールで作成および編集されたデータです…」の確認が出る

`node media/test-zip.js` で、ツールのコードで作った ZIP の中身（ハッシュの名前、欄）を確かめられる（`media/` で `npm i jszip@3.10.1` が要る）。
